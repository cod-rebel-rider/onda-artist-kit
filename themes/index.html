Como usar

Selecionar um tema

No arquivo data/site.json, defina a propriedade theme com o id do tema desejado:

{
  "theme": "midnight"
}

Recarregue o site. O conteúdo permanece o mesmo; apenas a aparência muda. Valores válidos: default, midnight, brutalist.

Se o tema informado não existir ou estiver incompleto, o Onda Artist Kit usa automaticamente o Theme Default — o site nunca fica quebrado.

Consulte o Theme Contract para aprender a criar o seu próprio theme.
